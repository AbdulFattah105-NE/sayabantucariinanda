# sayabantucariinanda

Halaman Link Hub bergaya glassmorphism yang menampilkan **Nama Toko** dan **Produk** dengan tautan affiliate disisipkan langsung pada masing-masing item.

## Struktur
- `index.html` — Daftar kategori **Nama Toko** dan **Produk** beserta tautan affiliate
- `css/style.css` — Tema Dark Aurora Glassmorphism responsif
- `js/script.js` — Filter kategori, salin tautan cepat, dan efek highlight kaca interaktif
- `favicon.svg` — Ikon halaman
